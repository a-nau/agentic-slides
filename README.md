# agentic-slides

Slide decks written **with coding agents**. Decks are Marp-style Markdown
rendered with [Quarto](https://quarto.org) (reveal.js); the agent skills bundled in
[`.agents/skills/`](.agents/skills/) build, review, and export them, and you
steer by commenting directly on the slides. The Quarto machinery (Marp-compat
filter and shim, ported theme, converter, deck server) lives in
[`quarto/`](quarto/README.md).

## Features

- **Agent-built decks**: repo intros, MR reviews, tool demos, and paper
  deep dives, with clickable SVG diagrams that deep-link into the source.
- **Live server**: every deck on one index page; saving a deck re-renders it
  (~2 s) and open pages swap in the changed slides without a reload.
- **Comment on slides**: select text → 💬. Comments land in a JSON file
  your agent works through. An **edit mode** lets you change a slide in the
  browser. See [docs](docs/comments-and-edit-mode.md).
- **Export** to PDF, **editable PPTX**, or a single self-contained HTML
  file ([docs](docs/exporting.md)).
- **GitHub Pages**: every push to `main` publishes all decks; HTML / PPTX /
  PDF downloads are opt-in ([docs](docs/publishing.md)).
- **Fact-checking**: check a paper deck's claims against the source PDF
  ([docs](docs/source-review.md)).
- **`agentic` theme**: dark, electric blue, with cards, columns, callouts, and
  a logo that links back here ([docs](docs/theme.md)).

**Comment on a slide**: select text, write what should change; the agent
works the comment into the deck.

**Review mode**: click a claim on the slide to open its passage in the paper;
click a passage in the paper to jump back to the slide that makes the claim.

## Quick start

Needs **Python 3**, **npm** (once, for the local MathJax and web fonts), `curl`, and **Google Chrome**
(PDF / editable-PPTX exports), on Linux (x86-64, arm64); macOS is untested
(needs at least `brew install flock`). The Python
lock file is generated for Python 3.12. No Docker, no system packages: setup
downloads Quarto's release into `quarto/.dist` and checks its SHA-256.

```bash
scripts/setup.sh                      # once: .venv, Quarto + MathJax + fonts (quarto/), git hooks
scripts/start.sh                      # http://localhost:8093 (scripts/stop.sh to stop)
SLIDES_HOST=0.0.0.0 scripts/start.sh  # same, reachable from other machines: trusted networks only (SECURITY.md)
                                      # both print a login URL (…/?token=…); SLIDES_AUTH=off: no login
scripts/install_services.sh           # optional: keep the server up as a systemd user unit
scripts/new_deck.sh tools/my-topic    # scaffold decks/tools/my-topic/slides.qmd
scripts/export.sh tools/my-topic pdf  # → exports/tools/my-topic.pdf
```

Each deck lives at `http://localhost:8093/<category>/<deck>/slides.md` (the
server returns the rendered deck); the comments/export API answers on :8094.
Migrating from Marp: `python3 quarto/scripts/marp2qmd.py <deck dir>` converts a
Marp `slides.md` deck in place, and a `slides.md` dropped into a deck folder is
converted on the fly while the server runs.

Example deck: [`decks/templates/visual-gallery/`](decks/templates/visual-gallery/)
shows what figures can do: a hover map and timeline of public driving datasets,
animated mechanisms (diffusion, attention, a driving planner), and build
pipelines, all generated by one script
([`make_figures.py`](decks/templates/visual-gallery/make_figures.py)), plus
title pages for each deck type and static overview figures.

Paper decks: [`decks/paper-reviews/`](decks/paper-reviews/) walks through four
classic papers (AlexNet, ResNet, Attention Is All You Need, NeRF), every figure
hand-drawn as SVG and linked to the paper section it explains.

## With an agent

Agents read [`AGENTS.md`](AGENTS.md) and the skills under
[`.agents/skills/`](.agents/skills/); nothing else to install. Claude Code
finds the same skills through the `.claude/skills` symlink.

| Skill | What it does |
|-------|--------------|
| [`onboarding`](.agents/skills/onboarding/SKILL.md) | Walks a newcomer through setup, a first deck, review, export, and publishing. |
| [`slide-deck`](.agents/skills/slide-deck/SKILL.md) | Builds a deck with clickable SVG figures; annotates and fact-checks sources. |
| [`deck-feedback`](.agents/skills/deck-feedback/SKILL.md) | Fresh-eyes comprehension review of a built deck by reviewer subagents. |
| [`address-feedback`](.agents/skills/address-feedback/SKILL.md) | Works open slide comments into the deck, then resolves them. |
| [`export-all-html`](.agents/skills/export-all-html/SKILL.md) | Exports every deck as a self-contained HTML bundle. |

Try *"how does this repo work?"* or *"make a deck introducing the repo at ~/code/foo"*.
